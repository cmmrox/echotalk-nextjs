# Legacy Project Archive

These files preserve the repository's earlier PRD, checkpoint progress, flat
implementation plans/logs, manual voice matrix, and initial S00 harness
artifacts.

They are provenance only:

- “done” means the historical implementation checkpoint was recorded; it does
  not prove current QA, UAT, release authorization, or production readiness.
- Provider and language choices may be stale.
- Relative links inside archived files may refer to their original locations.
- New work must not update these records.

Use [`docs/index.md`](../../index.md), approved feature records, and live
`delivery/` artifacts for current truth.
