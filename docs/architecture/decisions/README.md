# Architecture Decisions

Create `ADR-NNNN-short-title.md` from
[`docs/governance/templates/adr.md`](../../governance/templates/adr.md) for a
new service, data store, external provider, protocol, retention rule, security
boundary, cross-feature contract, or irreversible migration.

Statuses are `proposed`, `accepted`, `superseded`, or `rejected`. Accepted ADRs
must identify the feature/stage that validates the decision and its rollback or
migration consequences.
